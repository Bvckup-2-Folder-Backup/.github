# Bvckup 2

> Bvckup 2 keeps folder backup, delta copy, and the backup job on one destination path so the working set stays close to the source on that PC.

## Four Beats

1. **Name the job.** Give the Bvckup 2 session a short title before you point a working folder at a destination path.
2. **Pin the live folders.** Keep current folder backup and the backup job on the Bvckup 2 board and leave unused paths aside.
3. **Check the destination.** Read the Bvckup 2 summary of delta copy before you treat a pass as final.
4. **Close the loop.** Note which jobs are ready so the next Bvckup 2 visit does not start by hunting the destination path.

No. Bvckup 2 sits beside the labels, office notes, and working folders you already keep on your own PC.

**Can two office users share one computer?**

Yes. Bvckup 2 is meant to stay light during a normal copy session.

## Field Note

Bvckup 2 is easier to trust when the job stays smaller than the folder it came from. A named session shows which working set is active, the pins show which folder backup you will run today, and the closing note tells the next person which delta copy drives the destination path. That record is short on purpose: not a copy of every file, only the path back to the backup job that is still open on the reader's own folders.

The same loop fits a student lab folder, a client packet you own, or a computer shared by two office users. Open the last Bvckup 2 session, confirm one destination, and leave the backup job easier to follow than you found it. Other programs stay where they are. Bvckup 2 only holds the folder backup, the destination path, and the handoff.

## One Real Pass

Pick a folder that already has a name and that you own: a short project set, a lab packet on your desk, or a thin working directory. Open it in Bvckup 2, keep only that job on the board, and read one destination path you can point to. A pass is done when that path stays tied to the folder backup and the unused jobs are no longer in the way. Bvckup 2 does not need a full rebuild of the working set before it is useful.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first folder to the last destination, with the summary still matching the delta copy on that PC.
